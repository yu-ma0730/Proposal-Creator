# 提案文作成ツール
Proposal Creator

企業に提出する**提案文を AI で自動生成・改善**するツールです。

## 🚀 今すぐ使う

👉 **公開ページ：** https://yu-ma0730.github.io/Proposal-Creator/

## 特徴

✅ **5本の提案文を自動生成**
- 異なるアプローチから5パターンを提案
- あなたの強みと課題解決を活かした内容

✅ **客観的な評価表示**
- 複数視点での採点
- 説得力・実現可能性・カスタマイズ度など

✅ **別のAIで添削評価**
- ChatGPT / Gemini などで評価
- 評価結果を反映して自動改善

✅ **何度もリメイク可能**
- 納得まで何度でも改善
- 完成版をコピペで使用可能

---

## 使い方

### ステップ1：APIキー設定
Claude API キーを入力します。

### ステップ2：情報入力
```
【クライアント情報】
- 事業内容・業種
- 求めている成果・要件
- 予算
- 期間

【あなたの情報】
- 経験・得意分野
- 実績・成果事例
- 得意なアプローチ
```

### ステップ3：提案文を生成
AI が 5本の提案文を自動生成します。

**5つのアプローチ：**
1. **強み重視型** - あなたの強みを前面に打ち出す
2. **課題解決型** - クライアントの課題を深掘りして解決策を提示
3. **実績重視型** - 具体的な成功事例を活用
4. **信頼構築型** - 長期的なパートナーシップを提案
5. **カスタマイズ重視型** - クライアント特有のニーズに特化

### ステップ4：評価・改善

**各提案文に表示される評価：**
- 説得力 ⭐⭐⭐⭐☆
- 実現可能性 ⭐⭐⭐⭐⭐
- カスタマイズ度 ⭐⭐⭐☆☆
- 信頼性 ⭐⭐⭐⭐☆
- 実装スピード ⭐⭐⭐⭐⭐

**別のAIで添削：**
```
1. 「📋 添削テンプレートをコピー」ボタン
   ↓
2. ChatGPT / Gemini に貼り付けて評価依頼
   ↓
3. 評価結果をコピー
   ↓
4. 「添削結果を貼り付け」にペースト
   ↓
5. 「💡 添削を反映して改善」ボタンで自動改善
```

**完成版をコピー：**
```
「📋 完成版をコピー」で企業に提出可能な形でコピー
```

## 📊 3つのツールの使い分け

### 1️⃣ 案件評価ツール（Freelance-Proposal-Tool）
- **用途**：企業から受け取った案件が自分にできるか判定
- **URL**：https://yu-ma0730.github.io/Freelance-Proposal-Tool/

### 2️⃣ フィードバック管理ツール（Proposal-Feedback-Manager）
- **用途**：クライアント要望の修整案を複数生成
- **URL**：https://yu-ma0730.github.io/Proposal-Feedback-Manager/

### 3️⃣ 提案文作成ツール（Proposal-Creator）
- **用途**：企業に提出する提案文を最初から作成
- **URL**：https://yu-ma0730.github.io/Proposal-Creator/

## 🔄 完全なワークフロー例

```
【案件を受け取る】
   ↓
```
